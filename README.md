# Charango Tuner Pro Ecuador

A browser tuner for the five courses of the Andean charango, with a metronome built around folkloric rhythms. [Use it on itch.io](https://spacechakra.itch.io/charango-tuner-pro-ecuador).

## What it does

- Listens through your microphone and shows the nearest charango note and tuning offset.
- Includes metronome presets for Huayno, Sanjuanito, Carnavalito, Cueca, Chacarera, Taquirari, and Morenada.
- Can be installed as a progressive web app and used offline after the first load.

## Use it

Open the [live tuner](https://spacechakra.itch.io/charango-tuner-pro-ecuador), select **Start Tuner**, and allow microphone access. Pluck one course at a time and adjust it until the indicator is centered. Switch to **Metronome** to practice with a rhythm preset.

## Run locally

The app is plain HTML, CSS, and JavaScript. Serve this directory on `localhost` and open `index.html` in a modern browser. Microphone access requires a secure context, which includes `localhost` and HTTPS.
